# 开发过程中使用的提示

# 检查项目
忽略README.md文件，扫描并检查项目

# 前端中英文切换
给web端的首页添加中英文切换能力，在页面右上角添加语言切换下拉菜单，在用户选择 中文/English 选项时动态切换页面显示内容到对应语言。中英文语言资源文件需要保存在 web/qa-web/src/locales 目录中。只需要处理首页本身，无需处理其他页面。

网页的中的 24小时在线咨询 与台头部分还是不支持中英文切换

# 数据库构建
当前应用的数据全部使用json文件的方式在前端项目中存储，请将医生相关的数据使用mysql数据库存储。具体操作方式如下，

1.分析data目录下的json文件，问每一个json文件创建相应的sql脚本用于创建对应的数据库表，如patient-user对应创建的表名为patient_user.

2.分析data目录下的json文件，为每一条json文件中的数据创建对应的sql脚本用于将数据插入到对应的表中，表名与上一步创建的表名相同

3.创建 docker-compose.yml 用于创建mysql数据库，字符集使用utf-8，数据端口为3306对应本地对口也为3306，使用root用户，用户密码同样为root，不需要挂载磁盘、

4.在docker-compose.yml  创建phpmyadmin用于挂接上一步数生成的据库服务器，，端口3307,连接的数据使用的账号为root，密码同样为root

##执行数据库脚本

1.在数据库中执行上一部生成的sql脚本

2.使用root登录到数据执行简单的sql语句，查看数据是否成功落库

# 后端对接数据库
1.为后端配置相应的数据库，数据库使用之前在docker中创建的mysql数据库，地址端口为localhost:3306，用户：root，密码同样为root，数据库为qa_system，字符集使用utf-8

2.测试数据库连通性

1.在后端qa-service-user项目中为每一张数据表实现MVC三层架构代码构建

2.测试接口的功能是否完整，能否获取数据

# 前端数据变迁

1.前端现在调用数据的方式为使用本地data文件夹下的json文件，修改调用方式，调整为调用对应的后端接口获取相应数据

2.启动前端，测试联通性

# 患者登录接口设计

1.在 /docs 目录中编写规范的PRD文档模版

1.基于现在的项目，请在/docs中根据编写的PRD文档模版生成一份实现患者登录功能的PRD文档

1.基于患者登录功能的PRD文档在qa-service-question项目中生成患者登录/login的API接口符合MVC架构实现，对接数据库的端口为3306，地址为localhost，使用root用户，用户密码同样为root，字符集使用utf-8
