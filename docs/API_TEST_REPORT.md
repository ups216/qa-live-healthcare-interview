## 五、Bug修复记录

### 修复 #1：Bean Validation 校验链路断裂（严重）

| 项目 | 详情 |
|------|------|
| **文件** | `server/.../controller/PatientController.java` |
| **问题** | `register()` 和 `login()` 方法的 `@RequestBody` 参数缺少 `@Valid` 注解 |
| **影响** | DTO上的所有 `@NotBlank`、`@Size`、`@Pattern` 校验完全不生效 |
| **修复** | ① 参数前添加 `@Valid` ② 新增 `@ExceptionHandler(MethodArgumentNotValidException)` 统一异常处理 |

### 修复 #2：用户名大小写不敏感（中等）

| 项目 | 详情 |
|------|------|
| **文件** | `server/.../service/PatientService.java` |
| **问题** | 数据库 utf8mb4 collation 不区分大小写，导致 `TestUser` 和 `testuser` 匹配同一账号 |
| **风险** | 可能被利用绕过认证 |
| **修复** | 登录成功后增加 `inputUsername.equals(patient.getUsername())` 精确匹配校验 |

### 修复 #3：测试用例调整

| 调整内容 | 说明 |
|---------|------|
| API_TEST.md 版本升级至 v2.0 | 清理无效用例，修正预期值 |
| PAT-RG-405 预期调整为 400 | @Pattern 拦截含单引号的用户名 |
| PAT-RG-406 payload 缩短为 `<i>x</i>` | 满足 name 的 @Size(max=10) 约束 |
| PAT-LI-203/205 预期修正 | 超长输入→401, 非 JSON→415 |
| DOC-ID-002 断言放宽 | avatar/experience 为可选项可为 null |
| PAT-CU-101/PAT-RG-305 预期修正 | 缺失参数→400, 枚举外值→200 |
