## 4. 测试详情

### 4.1 TC-001: 正常注册

**请求：**
```bash
curl -X POST http://localhost:8080/api/patients/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test-user-001","password":"123456","name":"Test User","phone":"13800000001"}'
```

**响应：**
```json
{
  "phone": "13800000001",
  "name": "Test User",
  "id": "patient1787801960649",
  "username": "test-user-001"
}
```

**结论：** 注册功能正常，返回新创建的患者信息。

---

### 4.2 TC-002: 用户名重复注册

**请求：**
```bash
curl -X POST http://localhost:8080/api/patients/register \
  -H "Content-Type: application/json" \
  -d '{"username":"zhao-ming","password":"123456","name":"Duplicate User","phone":"13800000002"}'
```

**响应：**
```json
{
  "message": "用户名已存在"
}
```

**结论：** 重复用户名校验正常。

---

### 4.3 TC-005: 正常登录

**请求：**
```bash
curl -X POST http://localhost:8080/api/patients/login \
  -H "Content-Type: application/json" \
  -d '{"username":"zhao-ming","password":"123456"}'
```

**响应：**
```json
{
  "birthday": "1985-03-15",
  "gender": "男",
  "phone": "138****1234",
  "name": "赵明",
  "id": "patient001",
  "username": "zhao-ming"
}
```

**结论：** 登录功能正常，返回完整患者信息。

---

### 4.4 TC-006: 错误密码登录

**请求：**
```bash
curl -X POST http://localhost:8080/api/patients/login \
  -H "Content-Type: application/json" \
  -d '{"username":"zhao-ming","password":"wrong-password"}'
```

**响应：**
```json
{
  "message": "用户名或密码错误"
}
```

**结论：** 密码校验正常，错误提示不泄露具体原因（安全性）。

### 4.5 TC-011: 获取所有医生

**响应：** 返回 5 个医生，包含完整的 specialties 信息。

## 5. 问题与建议

### 5.1 已发现问题

| 问题 | 严重程度 | 状态 |
|------|----------|------|
| TC-004: 后端未实现用户名格式验证 | 低 | 建议优化 |

### 5.2 优化建议

1. **密码加密**：当前密码明文存储，建议使用 BCrypt 加密
2. **JWT Token**：登录后应返回 JWT Token 用于身份验证
3. **输入验证**：后端添加更完善的参数校验
4. **错误处理**：统一错误响应格式
