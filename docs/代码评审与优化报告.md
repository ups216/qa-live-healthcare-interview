## 三、代码质量审查

### 3.1 问题列表（按严重程度）

#### 严重（已在本轮修复）

| 问题 | 位置 | 处理 |
|------|------|------|
| 全局异常响应未统一 UTF-8 | GlobalExceptionHandler | 已设置 `MediaType.APPLICATION_JSON` 并指定 charset=UTF-8，与医生列表接口一致，避免错误页中文乱码。 |
| 并发调用 fetchDoctors 时第二调用无法复用同一请求 | store.fetchDoctors | 已改为「进行中则返回同一 Promise」：多处同时调用时只发一次请求，且所有调用方均可 await 同一结果，避免重复请求与竞态。 |

#### 中等（已建议或已标注）

| 问题 | 位置 | 建议/处理 |
|------|------|-----------|
| CORS 与 application.properties 不一致且生产不宜 * | CorsConfig / application.properties | CorsConfig 中 allowCredentials(true) + 通配符；properties 中 allow-credentials=false。以代码为准，生产应使用具体 allowedOrigins，已在 CorsConfig 增加注释。 |
| 密码明文存储 | data.sql / Doctor 实体 | 未改表结构；在报告中标注为技术债，生产环境应使用 BCrypt 等哈希存储。 |
| 医生登录密码来源与 API 数据源分离 | store + DoctorLogin | 登录校验用本地 doctor-user-list.json 的密码映射，与 MySQL 为两套数据源。当前数据一致可工作；若仅改 data.sql 未同步 JSON 会失效。建议路线图中增加「登录 API 化」或文档说明需同步两处。 |

#### 低

| 问题 | 位置 | 建议 |
|------|------|------|
| TestController 无类级说明 | TestController | 已补充类级注释，说明为 CORS 测试用。 |
| 前端错误信息展示 | Doctors.vue a-alert | 当前文案来自前端或 Error.message，风险低；若未来展示后端 message，需做转义或仅展示通用「加载失败」。 |

## 四、性能与优化

### 4.1 当前表现

- **GET /api/doctors**：全表查询，数据量约 5～数十条时性能可接受；无 N+1（单表、无懒加载关联）。
- **连接池**：Spring Boot 默认 HikariCP，已配置 maximum-pool-size/minimum-idle。

### 4.2 优化建议

| 方向 | 建议 | 优先级 |
|------|------|--------|
| 缓存 | 医生列表变更频率低，可对 findAll() 结果做短期缓存（如 Caffeine 5 分钟），降低 DB 压力。 | 中 |
| 分页 | 若医生数量显著增加，增加分页参数，避免一次加载过多。 | 中 |
| 索引 | 若按 is_active 筛选开放诊室，可考虑 is_active 索引；当前数据量可暂不建。 | 低 |
| 前端 | 医生列表可在前端做简单缓存（如 5 分钟内不重复请求），与「共享 Promise」一起减少重复请求。 | 低 |

### 4.3 可扩展性

- 新增医生字段：在 Entity、DTO、data.sql 中补充即可。
- 新增「按科室筛选」等：Repository 增加方法，Service/Controller 暴露参数即可，无需改动架构。

## 六、已实施的代码修改说明

以下修改已直接应用于代码库，且不改变现有功能行为。

1. **GlobalExceptionHandler 统一 UTF-8**  
   - 错误响应设置 `Content-Type: application/json;charset=UTF-8`，与 DoctorController 及 NFR-6 一致，避免错误页中文乱码。

2. **前端 store 并发请求**  
   - `fetchDoctors` 在「已加载中」时返回同一 in-flight Promise，避免并发调用触发多次请求，且所有调用方均可 await 同一结果。

3. **CorsConfig 注释**  
   - 增加类级注释：当前配置适用于开发/联调，生产环境应限制 allowedOrigins，并注意 allowCredentials 与 origin 的配合。

4. **TestController 注释**  
   - 增加类级注释，说明为 CORS 测试用接口。
