# 患者密码登录功能产品需求文档

## 1. 产品概述

### 1.1 产品背景
- 现有系统中，患者通过姓名和生日进行身份验证，缺少密码保护机制
- 为了提高系统安全性，保护患者隐私，需要增加密码登录功能
- 目标用户为需要使用在线问诊服务的患者

### 1.2 产品目标
- 实现患者密码登录功能，提高系统安全性
- 保持与现有验证流程的兼容性
- 提供密码重置功能，方便患者找回密码
- 确保密码存储安全，防止密码泄露

### 1.3 术语定义
- **患者**：使用在线问诊服务的用户
- **密码登录**：通过用户名和密码进行身份验证的方式
- **身份验证**：确认用户身份的过程
- **密码重置**：用户忘记密码时重新设置密码的过程

## 2. 核心功能

### 2.1 功能模块

| 模块名称 | 功能描述 |
|---------|----------|
| 患者密码登录 | 患者通过用户名和密码进行登录 |
| 密码设置 | 新患者注册时设置密码 |
| 密码重置 | 患者忘记密码时重置密码 |
| 密码修改 | 患者修改已有密码 |

### 2.2 功能详情

#### 2.2.1 患者密码登录
- **功能描述**：患者通过输入用户名（姓名）和密码进行登录
- **使用流程**：
  1. 患者进入登录页面
  2. 输入姓名和密码
  3. 点击登录按钮
  4. 系统验证身份
  5. 登录成功后进入患者门户
- **详细说明**：
  - 用户名使用患者姓名
  - 密码长度至少6位
  - 密码输入框显示密码可见性切换
  - 提供忘记密码链接
  - 登录失败时显示错误提示

#### 2.2.2 密码设置
- **功能描述**：新患者首次注册时设置密码
- **使用流程**：
  1. 患者输入姓名和生日
  2. 系统检测到新患者
  3. 弹出密码设置界面
  4. 患者设置密码
  5. 密码设置成功后自动登录
- **详细说明**：
  - 密码长度至少6位
  - 确认密码输入
  - 密码强度提示

#### 2.2.3 密码重置
- **功能描述**：患者忘记密码时通过验证身份信息重置密码
- **使用流程**：
  1. 患者点击忘记密码链接
  2. 输入姓名和生日进行身份验证
  3. 验证成功后设置新密码
  4. 密码重置成功后自动登录
- **详细说明**：
  - 身份验证使用姓名和生日
  - 新密码长度至少6位
  - 确认密码输入

#### 2.2.4 密码修改
- **功能描述**：已登录患者修改密码
- **使用流程**：
  1. 患者进入个人中心
  2. 点击修改密码
  3. 输入原密码和新密码
  4. 确认修改
- **详细说明**：
  - 需要验证原密码
  - 新密码长度至少6位
  - 确认新密码输入

## 3. 核心流程

### 3.1 用户角色

| 角色 | 权限 | 职责 |
|-----|------|------|
| 患者 | 登录、设置密码、重置密码、修改密码 | 使用在线问诊服务 |

### 3.2 业务流程

**患者登录流程**：
1. 患者进入登录页面
2. 输入姓名和密码
3. 系统验证身份
4. 验证成功 → 进入患者门户
5. 验证失败 → 显示错误提示

**新患者注册流程**：
1. 患者输入姓名和生日
2. 系统检测到新患者
3. 弹出密码设置界面
4. 患者设置密码
5. 系统创建患者账户并设置密码
6. 自动登录进入患者门户

**密码重置流程**：
1. 患者点击忘记密码链接
2. 输入姓名和生日
3. 系统验证身份
4. 验证成功 → 弹出密码设置界面
5. 患者设置新密码
6. 系统更新密码
7. 自动登录进入患者门户

| 登录页面 | 患者密码登录 | 患者通过姓名和密码登录 |
| 密码设置页面 | 密码设置 | 新患者设置密码 |
| 密码重置页面 | 密码重置 | 患者重置密码 |
| 个人中心页面 | 密码修改 | 患者修改密码 |

### 4.3 响应式设计
- **桌面端**：完整功能，水平布局

- **触摸设备**：优化输入体验，增大点击区域

## 5. 技术方案

### 5.1 技术栈
- **前端**：Vue 3, TypeScript, Ant Design Vue
- **后端**：Spring Boot, Java
- **数据库**：MySQL
- **密码加密**：BCrypt 加密算法

### 5.2 架构设计
- **前端**：
  - 修改 Consultation.vue 组件，添加密码登录功能
  - 新增密码设置、重置、修改组件
  - 使用 store 管理登录状态

- **后端**：
  - 修改 Patient 模型，添加 password 字段
  - 修改 PatientDao，支持密码相关操作
  - 修改 PatientService，添加密码验证、设置、重置功能
  - 修改 PatientController，添加密码相关 API

### 5.3 数据结构

**患者表（patient_user）**：
| 字段名 | 数据类型 | 描述 |
|-------|---------|------|
| id | VARCHAR(50) | 患者ID |
| name | VARCHAR(100) | 姓名 |
| birthday | DATE | 生日 |
| phone | VARCHAR(20) | 电话 |
| gender | VARCHAR(10) | 性别 |
| password | VARCHAR(255) | 加密后的密码 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

## 6. 部署与集成

### 6.1 部署方案
- **前端**：Vite 构建，部署到静态服务器
- **后端**：Spring Boot 打包为 JAR，部署到应用服务器
- **数据库**：MySQL 数据库，需要添加 password 字段

### 6.2 集成方案
- **前端集成**：修改现有 Consultation.vue 组件，添加密码登录功能
- **后端集成**：修改现有 Patient 相关代码，添加密码支持
- **数据库集成**：执行 SQL 脚本添加 password 字段
