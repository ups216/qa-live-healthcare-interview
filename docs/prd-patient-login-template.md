## 1. 概述

### 1.1 背景

当前问诊平台患者身份验证存在以下安全问题：

- **安全性不足**：无需密码即可登录，无法确保账户安全
- **身份冒用风险**：缺乏有效的身份验证机制
- **无法密码找回**：用户遗忘验证信息后无法恢复账户访问
- **缺乏用户体系**：无法积累患者历史问诊记录，影响连续性医疗服务

### 1.2 目标

为问诊患者提供安全的用户名密码登录方式，建立完整的患者账户体系，为后续功能扩展奠定基础。

### 1.3 范围

**前台功能（患者端）：**

- 患者注册页面（姓名、手机号、密码）
- 患者登录页面（用户名/手机号 + 密码）
- 登录状态保持（Token 持久化）
- 个人信息管理页面
- 退出登录功能

**后台功能（管理员端）：** 本次不做

## 3. 功能需求

### 3.1 功能列表

| 编号 | 功能名称 | 优先级 | 描述 |
|------|----------|--------|------|
| F01 | 患者注册 | P0 | 手机号注册，支持验证码校验 |
| F02 | 患者登录 | P0 | 手机号+密码登录 |
| F03 | 登录状态持久化 | P0 | JWT Token 管理，自动续期 |
| F04 | 退出登录 | P0 | 清除登录状态 |

### 3.2 详细功能说明

#### F01：患者注册

**页面路径：** `/patient/register`

**表单字段：**

| 字段名 | 类型 | 必填 | 校验规则 |
|--------|------|------|----------|
| 手机号 | string | 是 | 11位数字，以1开头 |
| 验证码 | string | 是 | 6位数字，5分钟有效 |
| 密码 | string | 是 | 8-20位，包含字母和数字 |
| 确认密码 | string | 是 | 与密码一致 |
| 姓名 | string | 是 | 2-20个字符 |

**业务流程：**

1. 用户输入手机号 → 点击获取验证码
2. 系统发送6位数字验证码到手机
3. 用户输入验证码、设置密码、确认密码、姓名
4. 提交注册 → 后端验证 → 创建账户
5. 注册成功后自动登录，跳转到首页

**验证码规则：**

- 同一手机号60秒内只能发送一次
- 验证码5分钟有效
- 验证失败可重试3次，超限需重新获取

#### F02：患者登录

**页面路径：** `/patient/login`

**表单字段：**

| 字段名 | 类型 | 必填 | 校验规则 |
|--------|------|------|----------|
| 手机号/用户名 | string | 是 | 手机号格式或已设置的用户名 |
| 密码 | string | 是 | - |

**业务流程：**

1. 用户输入手机号/用户名和密码
2. 点击登录 → 后端验证
3. 验证成功返回 JWT Token
4. 前端存储 Token，跳转到首页或来源页面

**错误处理：**

- 密码错误：提示"手机号或密码错误"，不区分具体是哪个字段错误
- 账户不存在：提示"该账户未注册"
- 登录失败5次：锁定账户15分钟

#### F03：登录状态持久化

**Token 管理：**

- Access Token：有效期2小时，用于API访问
- Refresh Token：有效期7天，用于刷新Access Token
- Token存储位置：前端 localStorage

**自动续期逻辑：**

1. 前端在Token过期前1分钟自动调用刷新接口
2. 刷新成功则更新Token，用户无感知
3. 刷新失败则跳转登录页面

#### F04：退出登录

**业务流程：**

1. 用户点击退出登录
2. 清除本地Token
3. 跳转登录页面

## 7. 安全需求

### 7.1 密码安全

- 密码必须加密存储（bcrypt）
- 前端密码传输使用 HTTPS
- 密码强度要求：8-20位，至少包含字母和数字

### 7.2 登录安全

- 同一账户连续失败5次，锁定15分钟
- 验证码错误3次，需重新获取
- 敏感操作需二次验证（如密码修改）

### 7.3 Token 安全

- Access Token 短期有效（2小时）
- Refresh Token 长期有效（7天），单设备使用
- 支持 Token 主动失效（退出登录时）

## 8. 非功能需求

### 8.1 性能需求

- 登录接口响应时间 < 500ms
- 注册接口响应时间 < 1s（含短信发送延迟）
- 支持 1000 并发登录

### 8.2 风险项

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 短信服务不可用 | 无法注册 | 提供异步队列，预留重试机制 |
| Token 安全漏洞 | 历史记录泄露 | 使用 HTTPS，定期安全审计 |

### 8.3 依赖项

| 依赖 | 说明 |
|------|------|
| 短信服务商 | 阿里云短信/腾讯云短信 |
| MySQL 数据库 | 现有服务已支持 |
| 后端 Spring Boot | 现有服务已支持 |
